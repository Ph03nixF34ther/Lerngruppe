# Definition
Gesamtheit aller Ressourcen, die benötigt werden, um die Kommunikation zu betreiben

Es gibt keine allgemeingültige Einteilung

# Arten von Netzen

## Breitbandige Zugangsnetze (Festnetz)

Grundlegendes Zugangsnetz für Private [[Computer]]

## Mobile und Drahtlose Zugangsnetze

Verbindung über z.B. WLAN

Zwischen Drahtlos und Mobil zu unterscheiden

| Anwendungsfall                                 | Drahtlos | Mobil |
| ---------------------------------------------- | -------- | ----- |
| Desktop PC                                     | Nein     | Nein  |
| Laptop an der Dose im Hotel                    | Nein     | Ja    |
| Netze in nicht verkabelten Gebäuden            | Ja       | Nein  |
| Inventur im Laden mit einem tragbaren Computer | Ja       | Ja    |

## Content Provider

Server die Daten (Content) zur Verfügung stellen

Viel Ost-West-Datenverkehr

## Transitnetze

Weiterleitung von Verkehr
