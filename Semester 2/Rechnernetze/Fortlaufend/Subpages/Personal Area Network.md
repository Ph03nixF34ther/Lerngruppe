# Erklärung

![[PAN.png]]

Ein PAN ist eine [[Netz#Größe von Netzen|Größeneinteilung von Computernetzen]].
In PANs kommunizieren Geräte in Reichweite einer Person.
Abstand zwischen

Kommunikationsteilnehmern ca. 1m
Unmittelbarer räumlicher Zusammenhang
„Im gleichen Raum“
# Beispiel

Ein Computer verbindet sich mit z.B. seinem Monitor, seiner Tastatur, und einem Drucker.
