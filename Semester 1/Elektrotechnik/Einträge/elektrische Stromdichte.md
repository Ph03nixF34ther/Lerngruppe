# Übersicht

Die elektrische Stromdichte beschreibt wie viel [[Ladung]] in einer Sekunde in einem [[Leiter]] durch einen Leiterquerschnitt von einem Quadratmeter, bzw. einem Quadratmillimeter befindet.

![[Leiterquerschnitt.svg]]

Formelzeichen: $J$ 

Formel: $J = \dfrac{I}{A}$

Einheit: $[J] = \dfrac{[I]}{[A]} = \dfrac{A}{m^2} \text{ Oftmals eher in } \dfrac{A}{mm^2}$
