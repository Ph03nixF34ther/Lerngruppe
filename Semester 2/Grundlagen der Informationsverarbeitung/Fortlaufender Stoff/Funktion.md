Eine Zuordnung einer Menge $A$ zu den Elementen einer Menge $B$

Jedem Element von $A$ darf nur ein Element von $B$ zugeordnet werden

Mehrere Elemente von $A$ können aber dem gleichen Element von $B$ zugeordnet werden

Sagen wir $f$ ist eine Funktion, dann ist die übliche Schreibweise 
$f : A \rightarrow B$ ($f$ ist eine Funktion von $A$ nach $B$)

$A$ ist der *Urbildbereich*
$B$ ist der *Bildbereich* oder *Wertebereich*

Es muss nicht jedem Element von $A$ ein Element von $B$ zugeordnet werden -> sie ist an dieser Stelle nicht definiert
Die Menge für die eine Definition/Zuordnung besteht heißt *Definitionsbereich*

Wenn eine Funktion $f$ einen Wert $a \in A$ einen Wert $b \in B$ zuordnet, heißt $b$ Bild von $a$ unter der Funktion $f$

Werden unter einer Funktion zu zwei unterschiedlichen Werten aus $A$ auch zwei unterschiedliche Werte aus $B$ zugeordnet, ist sie *Injektiv*

Wenn unter einer Funktion jedes $b$ als Bild vorkommt, ist sie *Surjektiv*

Ist eine Funktion sowohl *Surjektiv* als auch *Injektiv*, ist sie *eindeutig umkehrbar*
Unterschiedlichen $a \in A$ werden unterschiedlichen $b \in B$ zugeordnet werden und zu Bild $b$ existiert ein Urbild $a$ 
Es ist dann nicht nur möglich von $a$ auf $b$ zu schließen, sondern auch von $b$ auf $a$ und sie ist somit *bijektiv*
