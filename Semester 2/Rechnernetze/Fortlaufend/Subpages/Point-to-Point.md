# Erklärung

Bei der Übermittlung von Point to Point wird eine physische Verbindung zwischen zwei Kommunikationspartnern aufgebaut (gegebenenfalls auch über dritte), die dann für beide Kommunikationspartner reserviert ist.

![[Point_to_Point.png]]

Es gibt bei dieser Kommunikation nur einen Sender und einen Empfänger.
Die Point to Point Übermittlung  ist ein [[Einteilungsmöglichkeiten von Netzen#Einteilung über die technische Umsetzung|technisches Prinzip der Datenübermittlung]]
