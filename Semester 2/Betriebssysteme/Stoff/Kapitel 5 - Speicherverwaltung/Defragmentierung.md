# Defragmentierung

- dient zur Rückgewinnung und Reorganisation von Speicherplatz
- Verschub von belegten Speicherbereichen zur Gewinnung von großen freien Bereichen
- Welcher Speicher kann defragmentiert werden?
	- Hintergrundspeicher auf HDD-Festplatten
	- Hauptspeicher

# Speicherkompakttierung

- Zusammenschieben von belegten Bereichen im Speicher
- Ziel: Eine große Lücke statt vieler kleiner 
- effektives aber langsames und aufwendiges Verfahren
	- Hoher Verwaltungsaufwand

# Defragmentierung von HDD-Festplatten

- Problem:
	- Datenblöcke sind auf Festplatte verstreut abgelegt
- Maßnahme:
	- Zusammenlegen von zusammengehörigen Blöcken
- Folge:
	- Blöcke liegen nebeneinander auf der Festplatte ab
- Ergebnis:
	- Alle Informationen können in einem Zug gelesen werden

# Defragmentierung von SSD-Festplatten

- Blockweise Datenstruktur ohne Lesekopf
- Lage der Blöcke ist nicht relevant
- Unnötiger Verbrauch von Lese- und Schreibzyklen der SSD-Festplatte
