Kommt aus dem Griechischen und steht für "Zusammenordnung" oder "Lehre vom Satzbau"

Eine Sprache besteht aus einer Aneinanderreihung von Zeichen, die bestimmten Regeln folgen -> diese Regeln werden als Syntax bezeichnet

Die Syntax einer [[Programmiersprache]] legt fest, welche Zeichenreihen korrekt formulierte [[Programm|Programme]] 

Damit man feststellen kann, ob ein [[Programm]] syntaktisch richtig ist, muss die Sprache formal beschrieben werden
Das kann z.B. mit [[Automat|Automaten]] gemacht werden
-> Es wird eine [[Grammatik]] definiert

Ein Programm wird von einem [[Parser]] syntaktisch geprüft und dann kann der [[Compiler]] das Programm übersetzen
