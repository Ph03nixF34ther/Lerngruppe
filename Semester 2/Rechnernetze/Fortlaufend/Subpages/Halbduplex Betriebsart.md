# Erklärung

Der Halbduplex ist eine [[Einteilungsmöglichkeiten von Netzen#Einteilung über die Betriebsarten|Betriebsart]] von Netzwerkkommunikation.
Dabei fließen Daten ausschließlich von einem Datenpunkt zum nächsten.
Allerdings ist die Kommunikation auch in die andere Richtung möglich. Jedoch kann das nur dann passieren, wenn das Übertragungssystem nicht gerade vom Kommunikationspartner genutzt wird.
