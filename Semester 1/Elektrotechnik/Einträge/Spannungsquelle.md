# Übersicht

Eine [[Spannungsquelle]] ist ein wichtiger Teil Bestandteil vieler Stromnetze, da sie für Potenzialunterschiede sorgt, die dann [[elektrische Stromstärke|elektrische Stöme]] induzieren.

>[!Important] Merkhilfe: Innenwiderstand Spannungsquelle
>Der Innenwiderstand einer idealen Spannungsquelle ist $0\ \Omega$.
>Das kann man daran erkennen, dass das Schaltsymbol einer Gleichspannungsquelle einen durchgezogenen Strich vom Plus zum Minuspol besitzt. Es also keine Unterbrechung gibt.
